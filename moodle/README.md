# Плагин Moodle: «Виртуальная лаборатория Энерджиквантум»

Модуль-активность `mod_energy` — четыре интерактивных стенда внутри курса Moodle:
электрические цепи, возобновляемая энергетика, накопители и преобразователи,
энергоэффективность и умный дом.

Студент работает на стенде, выполняет задания — прогресс автоматически попадает
в журнал оценок Moodle. Преподаватель видит отчёт по группе и выгружает CSV.

## Что умеет

- **Один стенд или все четыре** — преподаватель отмечает нужные стенды в настройках активности,
  остальные скрываются из меню.
- **Автоматическая оценка** — количество выполненных заданий пересчитывается в балл
  (настраивается «заданий для полного балла», по умолчанию 3).
- **Сроки** — «Открыть с» / «Закрыть после»; вне интервала стенд не запускается.
- **Отчёт** — таблица «студент / заданий / звёзд / процент / время», экспорт CSV (разделитель `;`, BOM для Excel).
- **Приватность** — провайдер `classes/privacy/provider.php`: экспорт и удаление данных студента.
- **Резервное копирование** — настройки активности сохраняются и восстанавливаются вместе с курсом.
- **Работает без интернета** — стенд встроен в плагин (`standalone/lab.html`), внешних CDN нет.

## Установка

1. Скопируйте папку `energy` из этого каталога в Moodle:
   `moodle/mod/energy` — итоговая структура должна быть `mod/energy/version.php`.
2. Зайдите в Moodle как администратор → **Администрирование сайта → Уведомления**.
   Moodle сам создаст таблицы `energy` и `energy_progress`.
3. В курсе: **Добавить элемент или ресурс → Виртуальная лаборатория**.

### Ubuntu

```bash
sudo cp -r moodle/mod/energy /var/www/moodle/mod/
sudo chown -R www-data:www-data /var/www/moodle/mod/energy
sudo -u www-data php /var/www/moodle/admin/cli/upgrade.php --non-interactive
```

### Windows (XAMPP / IIS)

```bat
xcopy /E /I moodle\mod\energy C:\xampp\moodle\mod\energy
php C:\xampp\moodle\admin\cli\upgrade.php --non-interactive
```

### Готовый ZIP для «Установить плагин из ZIP»

```bash
cd moodle && zip -r ../mod_energy.zip mod/energy -x "*/.*"
```

В Moodle: **Администрирование сайта → Плагины → Установить плагины → из ZIP**.

## Как связаны стенд и Moodle

1. `view.php` отдаёт страницу с iframe на `standalone/lab.html` и передаёт настройки в JS.
2. `bridge.js` ждёт загрузки iframe, скрывает выключенные стенды и раз в 1,5 с читает
   состояние заданий из хуков сборки: `window.__lab`, `window.__renew`, `window.__storage`,
   `window.__eff` (у каждого — `solved()`: `{номер задания: звёзды}`).
3. Как только набор изменился — вызов AJAX `mod_energy_save_progress`.
4. Сервер объединяет прогресс (он только накапливается), сохраняет в `energy_progress`
   и обновляет оценку через `grade_update`.

## Обновление стенда в плагине

Стенд не редактируется вручную: правки вносятся в `src/` основного проекта, затем

```bash
npm run build      # обновит dist/lab.html, index.html и moodle/mod/energy/standalone/lab.html
```

## Проверка перед публикацией

```bash
cd moodle/mod/energy && php tools_check.php
```

Проверяются: наличие всех файлов, синтаксис PHP (`php -l`), валидность `db/install.xml`,
совпадение языковых ключей ru/en, наличие четырёх стендов и хуков прогресса в сборке,
объявление веб-сервиса и связка с мостом.

## Требования

- Moodle 4.0 и новее (проверено на структуре 4.x; `version.php` требует `2022041900`).
- PHP 7.4+ (рекомендуется 8.1+), расширения `xml`, `json` — стандартный набор Moodle.
- Сервер Moodle должен разрешать iframe с того же домена (по умолчанию разрешает).
