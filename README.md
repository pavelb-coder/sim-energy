# sim-energy · Виртуальная лаборатория «Энерджиквантум»

Интерактивный стенд по энергетике для направления «Энерджиквантум» (Кванториум).
Аналог [урокихимии.рф/lab.html](https://xn--h1aaaagokp0ay.xn--p1ai/lab.html) для электричества:
ребёнок собирает цепь мышью, замыкает ключ, жжёт лампу, ловит короткое замыкание и снимает
показания приборов в протокол.

**В репозитории — v1.0: все четыре стенда — «Электрические цепи», «Возобновляемая энергетика»,
«Накопители и преобразователи», «Энергоэффективность и умный дом».**
Дорожная карта остальных стендов — в [ТЗ](docs/Энерджиквантум_виртуальная_лаборатория_ТЗ.docx).

## Живая версия

Работает: **https://pavelb-coder.github.io/sim-energy/** (GitHub Pages, публикация из ветки `main`).

Как это устроено: `index.html` в корне — это собранный стенд (`dist/lab.html`).
После изменений в `src/` нужно обновить публикацию:

```bash
npm run build && cp dist/lab.html index.html && ./sync.sh -m "публикация"
```

Хотите автоматическую сборку при каждом пуше — добавьте CI-файл
`workflow-pages.template.yml` в `.github/workflows/pages.yml` (нужен токен со scope `workflow`)
и переключите Pages на **Source: GitHub Actions**.

Офлайн-вариант: `dist/lab.html` можно скачать и открыть двойным кликом — сервер не нужен.

## Что уже работает

- **Сцена-стол**: 10 видов оборудования — батарея, резистор, лампа, светодиод, реостат, ключ,
  предохранитель, амперметр, вольтметр, ваттметр. Перетаскивание, соединение клемм кликами,
  ортогональная разводка проводов, анимация тока.
- **Физика**: узловой анализ цепи (I = ε/(R + r)), нелинейная нить лампы (R(T) = R₂₀(1 + αΔT)),
  светодиод как кусочно-линейный элемент, нагрев и перегорание резистора, предохранитель,
  защита источника от перегрузки, учёт энергии в Вт·ч.
- **Приборы и время**: живые показания с «шлейфами»-графиками, множители времени ×1/×2/×4,
  журнал действий, протокол измерений, экспорт CSV (открывается в Excel, `;` и десятичная запятая).
- **Режимы**: «Свободный», «Задание» (6 квестов с автопроверкой и звёздами), «Проект»
  (название, цель, точки, печать протокола).
- **«Предскажи — проверь»**: до включения вводится ожидаемый ток, приложение показывает расхождение.
- **Доступность**: клавиатурная навигация (`Tab`, `Delete`, `M`, `Space`), зоны нажатия ≥ 44 px,
  адаптив под планшет и интерактивную панель.

### Стенд «Возобновляемая энергетика»

- **Сцена**: небо, солнце по времени суток и дате, облака, солнечная панель с наклоном и азимутом,
  ветрогенератор с 2/3/5 лопастями, дом-потребитель, накопитель с индикатором заряда,
  анимированные потоки энергии.
- **Физика**: положение солнца по широте 56° (Красноярск) и дню года, освещённость с учётом облачности,
  косинус угла падения света, нагрев модуля и его температурный коэффициент;
  мощность ветра `P = ½·ρ·A·v³·Cp` с Cp по числу лопастей, отсечка 2,5 и 16 м/с, номинал 150 Вт;
  контроллер заряда PWM (78 %) и MPPT (95 %); баланс энергии в накопителе.
- **Что считается**: мгновенные мощности, заряд АКБ, выработка и потребление за сутки,
  минимум заряда за сутки (проверка автономности), график суточной выработки со срезом по текущему времени.
- **6 заданий**: навести панель на солнце; солнце и облака; куб скорости ветра; MPPT против PWM;
  автономные сутки; лето и зима.

### Стенд «Накопители и преобразователи»

- **Накопители**: Li-ion 18650 (2,6 А·ч, 9,6 Вт·ч), LiFePO₄ 6 А·ч, свинцовый 12 В · 7 А·ч,
  ионистор 10 Ф. Кривая напряжения от заряда, внутреннее сопротивление, нагрев I²R.
- **Заряд CC/CV**: постоянный ток до 80 %, затем падение тока; отсечка по напряжению;
  ток задаётся в долях ёмкости (C-rate); пределы BMS и предупреждения.
- **Преобразователи**: buck (`Uвых = D·Uвх`), boost, инвертор 220 В с КПД, зависящим от загрузки;
  осциллограф показывает ШИМ и синусоиду.
- **Нагрузки**: лампа 5 Вт, двигатель 20 Вт, импульсная 50 Вт, инвертор 220 В · 60 Вт.
- **6 заданий**: полный заряд без перегрева; кривая разряда при разных токах; время автономии;
  импульс — батарея или ионистор; настроить buck на 5 В; КПД инвертора.

### Стенд «Энергоэффективность и умный дом»

- **Кабинет**: три помещения (кабинет 24 м², коридор, лаборатория), 15 светильников,
  три типа ламп (накаливания 60 Вт / люминесцентная 15 Вт / светодиодная 9 Вт при сопоставимом потоке).
- **Автоматика**: датчик движения, сумеречное реле, умная розетка — меняют не мощность, а часы работы.
- **Приборы**: чайник, холодильник, компьютер, телевизор, «зарядка в розетке» — с режимом ожидания.
- **Что считается**: кВт·ч за сутки, стоимость по тарифу 3,2 ₽, экономия в процентах и рублях,
  освещённость и её соответствие нормам (400/150/500 лк), окупаемость замены ламп, суточный профиль.
- **6 заданий**: снизить потребление на 30 %; три лампы при равном свете; окупаемость замены;
  найти «вампиров»; сценарий «умный дом»; протокол энергоаудита.

## Производительность интерфейса

Иконки оборудования рисуются общим SVG-спрайтом (`<symbol id="ic-…">` в начале `body`),
в сцене остаётся один `<use href="#ic-…">` на деталь. Записи в DOM идут через `window.UI`
(`text/html/attr/cls`): значение сравнивается с предыдущим и пишется только при изменении.
Показания приборов, журнальные строки и графики обновляются 10 раз в секунду вместо 60,
анимация ротора и солнца — с пониженной частотой. Замеры (Chromium, 1440×950, MutationObserver):

| Стенд | Мутаций DOM в секунду (до → после) | FPS |
|---|---|---|
| Электрические цепи | 1092 → 72 | 60 |
| Возобновляемая энергетика | 2940 → 142 | 60 |
| Накопители | 2903 → 98 | 60 |
| Энергоэффективность | 2529 → 51 | 60 |

## Синхронизация с репозиторием

```bash
./sync.sh                  # сборка → тесты → коммит → push
./sync.sh -m "текст"       # то же, со своим сообщением коммита
./sync.sh --status         # что расходится с origin/main
./sync.sh --pull           # только забрать изменения из репозитория
```

Перед коммитом `pre-commit`-хук пересобирает `dist/lab.html` и прогоняет тесты физики,
поэтому опубликованный файл всегда соответствует исходникам.
Токен читается из `~/.gh_token` (права 600) и в репозиторий не записывается.

## Сборка и проверки

```bash
npm run build      # dist/lab.html — один файл, открывается двойным кликом
npm test           # проверка физики обоих стендов (цепи + ВИЭ)
```

`dist/lab.html` не требует сервера, интернета и установки: его можно положить на флешку и
открыть на любом ноутбуке квантума.

## Модель упрощена осознанно

Это учебная модель, а не инженерный симулятор: провода идеальные, переменный ток не
моделируется, кривая разряда батареи — кусочно-линейная. Критерий качества — совпадение с
натурным стендом в пределах 10 % по току и мощности (см. ТЗ, раздел 7).
