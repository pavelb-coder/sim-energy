# sim-energy · Виртуальная лаборатория «Энерджиквантум»

Интерактивный стенд по энергетике для направления «Энерджиквантум» (Кванториум).
Аналог [урокихимии.рф/lab.html](https://xn--h1aaaagokp0ay.xn--p1ai/lab.html) для электричества:
ребёнок собирает цепь мышью, замыкает ключ, жжёт лампу, ловит короткое замыкание и снимает
показания приборов в протокол.

**В репозитории — v1.2: шесть стендов — «Электрические цепи», «Возобновляемая энергетика»,
«Накопители и преобразователи», «Энергоэффективность и умный дом», «Водородный контур»** (набор
в духе Horizon Energy Box FCJJ-40) **и «Микросеть»** (солнце + ветер + накопитель + сеть + зарядка
электромобиля). На каждом стенде — **8 лабораторных работ** (48 всего), у каждой: цель, шаги,
три подсказки, автооценка в звёздах и разбор «почему так».
Дорожная карта остальных стендов — в [ТЗ](docs/Энерджиквантум_виртуальная_лаборатория_ТЗ.docx).

## Живая версия

Работает: **https://pavelb-coder.github.io/sim-energy/** (GitHub Pages, публикация из ветки `main`).

Как это устроено: `index.html` в корне — это собранный стенд (`dist/lab.html`).
После изменений в `src/` нужно обновить публикацию:

```bash
npm run build && cp dist/lab.html index.html && ./sync.sh -m "публикация"
```

Хотите автоматическую сборку при каждом пуше — добавьте CI-файл
`workflow-pages.template.yml` в `.github/workflows/pages.yml` (нужен токен со scope `workflow`)
и переключите Pages на **Source: GitHub Actions**.

Офлайн-вариант: `dist/lab.html` можно скачать и открыть двойным кликом — сервер не нужен.

## Moodle

Для встраивания лаборатории в курс собран плагин-активность `mod_energy`
(каталог `moodle/mod/energy`, ветка `moodle-plugin`): шесть стендов внутри Moodle,
автоматическая оценка по выполненным заданиям, отчёт для преподавателя и CSV.
Готовый архив — `moodle/mod_energy.zip`.

```bash
npm run build           # обновит и плагин: moodle/mod/energy/standalone/lab.html
cd moodle && zip -r mod_energy.zip mod/energy -x "*/.*"
```

**Ветка `moodle-plugin` обновляется автоматически вместе с `main`:**

- `./sync.sh` — в конце сам переводит `moodle-plugin` на свежий `main`, пересобирает стенд
  внутри плагина, архив `mod_energy.zip` и прогоняет `php tools_check.php`;
- `./sync.sh --moodle` — только обновить ветку плагина, без коммита в `main`;
- `./sync.sh --no-moodle` — не трогать ветку плагина;
- для CI есть шаблон `workflow-sync-moodle.template.yml`: при пуше в `main`
  GitHub Actions сам переносит изменения в `moodle-plugin` и собирает плагин
  (инструкция по включению — в первых строках файла).

Подробности — [moodle/README.md](moodle/README.md).

## Локальный запуск (порт 8082)

Как в `sim-chemistry`: тот же лёгкий сервер на Node без зависимостей.
Готовые скрипты лежат в корне проекта — они сами находят Node.js, а если его нет,
переключаются на Python или открывают готовую сборку.

### Windows

| Способ | Что делать |
|---|---|
| Двойной клик | `start.bat` — запускает сервер и печатает адрес |
| PowerShell | `powershell -ExecutionPolicy Bypass -File .\start.ps1` |
| Командная строка | `npm start` (нужен установленный [Node.js](https://nodejs.org), LTS) |

Откройте в браузере **http://localhost:8082** (адрес печатается в консоли). Порт можно поменять:
`set PORT=9000 && start.bat`. Остановка — `Ctrl+C` в окне консоли.

### Ubuntu / Linux / macOS

```bash
chmod +x start.sh      # один раз
./start.sh             # или PORT=9000 ./start.sh
```

Если Node.js не установлен:

```bash
sudo apt update && sudo apt install -y nodejs     # Ubuntu 22.04+
# либо без Node вовсе:
./start.sh --python                                # нужен python3
```

Проверка версий: `node -v` (нужен 18+), `python3 -V` (любой 3.x).

### Если сервер не нужен

`dist/lab.html` — полностью автономный файл: его можно скопировать на флешку и открыть
двойным кликом в любом браузере, интернет и установка чего-либо не требуются.

- Порт меняется переменной: `PORT=9000 npm start`.
- Адреса-псевдонимы: `/`, `/lab`, `/lab.html`, `/sim` → собранный стенд, `/dist` → `dist/lab.html`.
- Отдаётся brotli/gzip (265 КБ → 66 КБ), кэш отключён — после `npm run build` достаточно обновить страницу.
- `HOST` по умолчанию `0.0.0.0`, чтобы стенд был виден и с другого компьютера в локальной сети.

Проверка после правок в `src/`:

```bash
npm run build && npm test && npm start
```

## Что уже работает

- **Сцена-стол**: 10 видов оборудования — батарея, резистор, лампа, светодиод, реостат, ключ,
  предохранитель, амперметр, вольтметр, ваттметр. Перетаскивание, соединение клемм кликами,
  ортогональная разводка проводов, анимация тока.
- **Физика**: узловой анализ цепи (I = ε/(R + r)), нелинейная нить лампы (R(T) = R₂₀(1 + αΔT)),
  светодиод как кусочно-линейный элемент, нагрев и перегорание резистора, предохранитель,
  защита источника от перегрузки, учёт энергии в Вт·ч.
- **Приборы и время**: живые показания с «шлейфами»-графиками, множители времени ×1/×2/×4,
  журнал действий, протокол измерений, экспорт CSV (открывается в Excel, `;` и десятичная запятая).
- **Режимы**: «Свободный», «Задание» (6 квестов с автопроверкой и звёздами), «Проект»
  (название, цель, точки, печать протокола).
- **«Предскажи — проверь»**: до включения вводится ожидаемый ток, приложение показывает расхождение.
- **Доступность**: клавиатурная навигация (`Tab`, `Delete`, `M`, `Space`), зоны нажатия ≥ 44 px,
  адаптив под планшет и интерактивную панель.

### Стенд «Возобновляемая энергетика»

- **Сцена**: небо, солнце по времени суток и дате, облака, солнечная панель с наклоном и азимутом,
  ветрогенератор с 2/3/5 лопастями, дом-потребитель, накопитель с индикатором заряда,
  анимированные потоки энергии.
- **Физика**: положение солнца по широте 56° (Красноярск) и дню года, освещённость с учётом облачности,
  косинус угла падения света, нагрев модуля и его температурный коэффициент;
  мощность ветра `P = ½·ρ·A·v³·Cp` с Cp по числу лопастей, отсечка 2,5 и 16 м/с, номинал 150 Вт;
  контроллер заряда PWM (78 %) и MPPT (95 %); баланс энергии в накопителе.
- **Что считается**: мгновенные мощности, заряд АКБ, выработка и потребление за сутки,
  минимум заряда за сутки (проверка автономности), график суточной выработки со срезом по текущему времени.
- **6 заданий**: навести панель на солнце; солнце и облака; куб скорости ветра; MPPT против PWM;
  автономные сутки; лето и зима.

### Стенд «Накопители и преобразователи»

- **Накопители**: Li-ion 18650 (2,6 А·ч, 9,6 Вт·ч), LiFePO₄ 6 А·ч, свинцовый 12 В · 7 А·ч,
  ионистор 10 Ф. Кривая напряжения от заряда, внутреннее сопротивление, нагрев I²R.
- **Заряд CC/CV**: постоянный ток до 80 %, затем падение тока; отсечка по напряжению;
  ток задаётся в долях ёмкости (C-rate); пределы BMS и предупреждения.
- **Преобразователи**: buck (`Uвых = D·Uвх`), boost, инвертор 220 В с КПД, зависящим от загрузки;
  осциллограф показывает ШИМ и синусоиду.
- **Нагрузки**: лампа 5 Вт, двигатель 20 Вт, импульсная 50 Вт, инвертор 220 В · 60 Вт.
- **6 заданий**: полный заряд без перегрева; кривая разряда при разных токах; время автономии;
  импульс — батарея или ионистор; настроить buck на 5 В; КПД инвертора.

### Стенд «Энергоэффективность и умный дом»

- **Кабинет**: три помещения (кабинет 24 м², коридор, лаборатория), 15 светильников,
  три типа ламп (накаливания 60 Вт / люминесцентная 15 Вт / светодиодная 9 Вт при сопоставимом потоке).
- **Автоматика**: датчик движения, сумеречное реле, умная розетка — меняют не мощность, а часы работы.
- **Приборы**: чайник, холодильник, компьютер, телевизор, «зарядка в розетке» — с режимом ожидания.
- **Что считается**: кВт·ч за сутки, стоимость по тарифу 3,2 ₽, экономия в процентах и рублях,
  освещённость и её соответствие нормам (400/150/500 лк), окупаемость замены ламп, суточный профиль.
- **6 заданий**: снизить потребление на 30 %; три лампы при равном свете; окупаемость замены;
  найти «вампиров»; сценарий «умный дом»; протокол энергоаудита.

### Стенд «Водородный контур» (по мотивам Horizon Energy Box FCJJ-40)

- **Обратимый PEM-элемент**: электролиз воды ↔ топливный элемент, мембрана 25 × 25 мм,
  порог разложения 1,48 В, ВАХ топливного элемента 0,6–0,9 В на ячейку.
- **Баки**: H₂ и O₂ по 12,5 мл, газ считается по закону Фарадея (1 А → 7,5 мл H₂ в минуту,
  кислорода вдвое меньше по объёму).
- **Источники**: солнечная панель (освещённость, наклон, угол солнца, тень, нагрев),
  ветрогенератор (P ~ v³, ограничение по шторму), кривошип, батарейный блок 2 × AA (3 В).
- **Нагрузки**: светодиод, вентилятор, машинка, резистор (вольтметр — режим холостого хода).
- **Оформление в духе набора**: белые пластиковые модули с синими винтами и гравировкой
  (`HORIZON ENERGY BOX · FCJJ-40`), герметичные цилиндры с пузырьками при электролизе,
  баки H₂/O₂ со шкалой, мультиметр с ЖК-табло, вращающиеся ротор ветряка и крыльчатка,
  панель АА-батарей, слот для сменных химических модулей; оранжевые ползунки и клеммы «банан».
- **Другие элементы набора**: этаноловый (5–15 %, выше 15 % — деградация), солевой
  (до 1,2 В / 200 мА, магниевый анод расходуется), термоэлектрический (≈ 21 мВ на 1 °C разницы).
- **8 заданий**: разложить воду; зажечь светодиод; раскрутить вентилятор (≥ 40 мВт);
  солнечный электролиз; ветряной электролиз; машинка ≥ 100 см/с; сравнить три химических
  источника; найти минимальное напряжение устойчивого электролиза.

## Стенд «Микросеть» (новый)

Солнце, ветер, накопитель, сеть, электромобиль и резервный ДГУ в одной сцене. Время идёт,
сутки прокручиваются кнопками ×1 / ×4 / ×12, есть островной режим.

- **Солнце**: 3 кВт панелей при наклоне 40° и юге в ясный полдень дают ≈ 1,93 кВт (≈ 12,9 кВт·ч/сутки);
  азимут 90° снижает до ≈ 1,31 кВт, север — до ≈ 0,63 кВт.
- **Ветер**: скорость на высоте `v = v10 · (h/10)^0,14`, cut-in 3 м/с, номинал 11 м/с, cut-out 22 м/с.
- **Тарифы**: день (7–23) 5,2 ₽/кВт·ч, ночь 2,6 ₽, отдача в сеть 2,2 ₽.
- **CO₂**: сеть 0,42 кг/кВт·ч, ДГУ 0,20 кг/кВт·ч.
- **Зарядка EV ночью** стоит 2,59 ₽/кВт·ч против 5,17 ₽/кВт·ч вечером — экономия ≈ 144 ₽/сутки при 7 кВт.
- **8 заданий**: сбалансировать сутки; собственное потребление ≥ 70 %; автономность в островном
  режиме; ночной тариф; меньше CO₂ на 40 %; вечерний пик; две лабораторные работы по методике
  измерений (облачность и выработка, оптимальный наклон панели).

## Лабораторные работы (v1.2)

К каждой работе: цель → шаги → три подсказки по кнопке → автооценка (проверка в любой момент,
звёзды 1–3) → разбор «почему так». Список добавленного:

| Стенд | Новые работы |
|---|---|
| Электрические цепи | Параллельное соединение (напряжения равны, токи складываются); Энергия и стоимость (Вт·ч и работа тока) |
| Возобновляемая энергетика | Наклон панели (поиск оптимума по точкам); Число лопастей (ометаемая площадь) |
| Накопители | Сравнить два типа АКБ; Нагрев при заряде (I²·r и температурная защита) |
| Эффективность | Профиль нагрузки (поиск пика); Датчик движения (экономия ≥ 25 % без замены ламп) |
| Водородный контур | Сравнить источники (три химических элемента); Минимум разложения (порог ≈ 1,48 В) |
| Микросеть | Облачность и выработка; Оптимальный наклон панели |

## Производительность интерфейса

Иконки оборудования рисуются общим SVG-спрайтом (`<symbol id="ic-…">` в начале `body`),
в сцене остаётся один `<use href="#ic-…">` на деталь. Записи в DOM идут через `window.UI`
(`text/html/attr/cls`): значение сравнивается с предыдущим и пишется только при изменении.
Показания приборов, журнальные строки и графики обновляются 10 раз в секунду вместо 60,
анимация ротора и солнца — с пониженной частотой. Замеры (Chromium, 1440×950, MutationObserver):

| Стенд | Мутаций DOM в секунду (до → после) | FPS |
|---|---|---|
| Электрические цепи | 1092 → 72 | 60 |
| Возобновляемая энергетика | 2940 → 142 | 60 |
| Накопители | 2903 → 98 | 60 |
| Энергоэффективность | 2529 → 51 | 60 |

## Синхронизация с репозиторием

```bash
./sync.sh                  # сборка → тесты → коммит → push
./sync.sh -m "текст"       # то же, со своим сообщением коммита
./sync.sh --status         # что расходится с origin/main
./sync.sh --pull           # только забрать изменения из репозитория
```

Перед коммитом `pre-commit`-хук пересобирает `dist/lab.html` и прогоняет тесты физики,
поэтому опубликованный файл всегда соответствует исходникам.
Токен читается из `~/.gh_token` (права 600) и в репозиторий не записывается.

## Сборка и проверки

npm run build      # dist/lab.html — один файл, открывается двойным кликом
npm test           # проверка физики всех шести стендов

`dist/lab.html` не требует сервера, интернета и установки: его можно положить на флешку и
